# Screenshots

Screenshots for the Nextcloud App Store and the documentation, 1600 × 1000
pixels, taken in Nextcloud 33 with the public demo data from `tools/demo/`
(invented choir "Demochor", CC0). The accounts have neutral names such as
"Demo Librarian" and "Demo Conductor". The only real persons shown are
composers and lyricists who died more than 70 years ago.

| File | Caption |
|---|---|
| `01-catalog-with-filters.png` | The catalog: shelf mark, title, composer, rights status and repertoire at a glance, with search and filters in the navigation. |
| `02-copy-rights.png` | A copy with its rights: confirmed public domain status with reason and evidence, releases for the singers' portal and the print station, the version valid for the choir and the protection proposal from the life dates of the persons involved. |
| `03-score-voice-focus.png` | The score in the browser: a range of measures, the focus voice (Tenor II) highlighted and emphasised during playback, a text reference, internal excerpt links and tasks for this place. |
| `04-concert-planning.png` | Planning a concert: pieces in order with durations, reordering with buttons, and warnings about rights, preservation copies and the version valid for the choir. |
| `05-start-page-due.png` | The start page "Due": what the user's roles need now, with the open tasks sorted by archive binder. |
| `06-merge-proposals-german.png` | Maintaining the catalog in German: proposals to merge works that are listed twice; every merge can be undone. |
| `07-score-dark-theme.png` | The score view in the dark theme. |

All screenshots use the light theme and the English interface, except
`06` (German) and `07` (dark theme).
